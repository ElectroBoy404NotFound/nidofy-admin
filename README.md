# Nidofy Admin

This is the admin dashboard for my portfolio site, Nidofy.

It allows me to manage content displayed on the main website without having to manually modify the site itself.

## Features

* Allows me to manage content on my portfolio

* Allows me to manage poems

* Provides an admin interface for Nidofy

* Connects to the Nidofy backend

## Tech Stack

* Frontend: HTML, CSS, JS + Bootstrap, Marked

* Backend: Java (Spring Boot) (Same as for Nidofy, it's a shared backend)

## Backend

You can find more about the backend here:

https://github.com/ElectroBoy404NotFound/nidofy/tree/main/nidofy-backend

## Deploying

Once the repo is cloned, run:

`npm i`

Then build the project:

`npm run build`

Finally, start it with:

`npm start`
